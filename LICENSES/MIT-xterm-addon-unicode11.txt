This license applies to the Unicode 11 cell-width range tables and the
wcwidth fall-through in
android/client-core/src/main/kotlin/io/github/rfairburn/pireviewgate/core/input/UnicodeCellWidths.kt,
which are a mechanical port from:

  @xterm/addon-unicode11@0.9.0, src/UnicodeV11.ts
  https://github.com/xtermjs/xterm.js
  Copyright (c) 2019 The xterm.js authors

The BMP combining, BMP wide, supplementary combining, and supplementary wide
range lists are reproduced verbatim from that file (verified ascending and
non-overlapping), and UnicodeCellWidths.width reproduces that file's wcwidth
fall-through: 0 below 32, 1 below 127, the built BMP table below 0x10000, then
the supplementary combining and wide ranges. No other part of the upstream
package is included, and the port adds no glyph measurement, device lookup, or
substituted table.

The same notice is packaged inside the Android application under
app/src/main/assets/licenses/MIT-xterm-addon-unicode11.txt so the attribution
travels with the installed app as well as with the source distribution.
